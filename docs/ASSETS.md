# 资料与媒体

万灵卷的 282 个创作条目与 1692 幅作品来自本项目六批次《山海经》配图、创作稿与原文考据；“条目”包含分项、替代题名和创作备稿，不能直接等同于 282 种不同异兽。

- `assets/works/`：每条目六种画境的 WebP 浏览副本。
- `assets/sources/`：各批次 Markdown 来源稿与生成清单。
- `data.js`：保留原文、出处、考据和创作边界的游戏图鉴数据。
- `docs/media/`：原画排版封面、真实游戏截图与战斗动图。
- `trailer/`：项目原画、实际游戏录屏、原创合成器乐和音效组成的两版宣传片。

六种画境为电影主视觉、工笔重彩、月夜叙事、收藏玩具、剪影海报、极简水墨。原 PNG 和原始命名在创作档案中另行保留；仓库中提供适合浏览与离线游玩的副本。

五行、稀有度、能力、境域规则、路线和剧情属于游戏演绎。来源不同的同名形象分别保留；文献信息以条目原文与考据为准。

公开副本将来源记录中的本机盘符路径换成随包的相对文档路径，便于克隆与离线阅读。它没有改动画作、资料正文或游戏机制。

本仓库尚未附加开源许可证。
